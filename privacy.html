개인정보처리방침 / Privacy Policy

시행일 / Effective date: 2026-11-14

1. 대상 / Scope

CLAUD는 소유자 본인 한 명만 사용하는 개인용 도구입니다. 다른 사람의 계정에 접근하지 않으며, 다른 사용자를 받지 않습니다.
CLAUD is a personal tool used only by its owner. It does not access anyone else's account and does not accept other users.

2. 접근하는 정보 / Data accessed

소유자가 구글 로그인 화면에서 직접 허용한 범위 안에서, 소유자 본인의 Gmail, Calendar, Tasks, Contacts, Drive 데이터에 접근합니다.
Within the scopes the owner grants on the Google sign-in screen, the tool accesses the owner's own Gmail, Calendar, Tasks, Contacts and Drive data.

3. 사용 목적 / How data is used

개인 메모와 일일 요약을 만들고 본인 메일함을 정리하는 데에만 사용합니다. 광고, 판매, 프로파일링에 쓰지 않습니다.
Data is used only to create private notes and daily summaries and to tidy the owner's own mailbox. It is never used for advertising, sale or profiling.

4. 보관과 공유 / Storage and sharing

데이터는 소유자의 컴퓨터와 소유자 본인의 저장소에만 보관합니다. 제3자에게 판매하거나 공유하지 않습니다. 요약을 만들 때 소유자가 선택한 AI 처리 서비스로 내용 일부가 전달될 수 있으며, 그 밖의 용도로는 전달하지 않습니다.
Data is stored only on the owner's own computer and storage. It is not sold to or shared with third parties. When producing summaries, portions of content may be sent to an AI processing service chosen by the owner, and for no other purpose.

5. Google API 데이터 / Google API data

이 도구가 Google API로 받은 정보의 사용과 다른 앱으로의 전달은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. 접근 해제 / Revoking access

소유자는 언제든 Google 계정 권한 페이지에서 접근을 해제할 수 있습니다.
The owner can revoke access at any time from the Google Account permissions page.
